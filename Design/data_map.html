Importer / Route
import_branch_stats()
Reads Year, Month, BRANCH + 54 column headers via BRANCH_STATS_MAP. Upserts — safe to re-upload same file. Skips desk branches and locker branches.
import_online_stats()
Reads Year, Month + 24 column headers via ONLINE_STATS_MAP. No branch dimension — system-wide entries only.
import_quarterly_ref()
Reads Year, Quarter, Branch, value. Sums multiple rows for same branch/quarter. Skips if entry already exists.
import_sirsi_checkouts()
Auto-detected from sheet header. Parses year/month from report title. Sums Charge Item + Renew Item per branch → circulation total. A-HOTSPOT shelving location → hotspot circulation. Also writes raw rows to SirsiCheckout table.
import_new_library_users()
Auto-detected from sheet header. Maps patron profiles to Adult / Juvenile. Writes Adult, Juvenile, and Total registration counts.
import_door_count()
Reads daily Ins per location. Aggregates to monthly Gate Count per branch. Branch mapped via DOOR_COUNT_BRANCH_MAP.
import_princh()
Reads per-document page counts. Sums all paper sizes per branch per month → Total Prints per Month.
Manual entry routes
/entries/new and /entries/<id>/edit write to any category. Upload-sourced metrics hidden from form (circulation, prints, new cards).
Annual survey routes
/annual-survey/<year>/enter writes AnnualSurveyValue rows. /annual-survey/<year>/calculate auto-fills ~40 metrics from Branch Stats + Online Stats FY aggregates.
