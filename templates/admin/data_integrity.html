Data Integrity Check

Compares Branch Stats "Total Branch Circulation" against the raw SIRSI checkout detail table (sirsi_checkouts), branch by branch and month by month; checks for duplicate Entry rows; flags metrics recorded for a branch documented as never tracking them (e.g. WiFi for Bookmobile/Outreach); and flags registration entries where Adult + Juvenile doesn't equal the stored Total. Run this anytime you want to verify the numbers on a report without asking anyone to just trust them.
